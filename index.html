ESP32-C3 Lab BLE-driven labs for Robot-01

Disconnected

Six single-purpose labs that talk to your Robot-01 over Web Bluetooth (Nordic UART). Pick one below.

// browser support Heads-up: BLE works in Chrome / Edge only. Firefox + Safari can't do Web Bluetooth.
🕹️

Drive

Joystick → motors. Forward, back, turn, pivot.

 ⚙️

Servo

Sliders + sweep. Plug servos into J4 / J5.

 💡

LEDs

Toggle the 4 status LEDs (D5–D8).

 🌈

NeoPixels

Color the 4 onboard RGB pixels (D1–D4).

 📡

Distance

Live ultrasonic reading (HC-SR04 on J6).

 🎹

Buzzer

Piano + freq slider for the on-board piezo.
