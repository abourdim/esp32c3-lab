D5 · D6 · D7 · D8

Toggle the four discrete status LEDs. Each click sends LED:i,on. Note: D5/D6 are wired to the same pin as motor A direction (GPIO 1), D7/D8 to motor B speed (GPIO 10) — they double as visual feedback when motors run.

// note On the v3 board these aren't independently dimmable. The LED: command is implemented but the firmware ignores it when motors are active (to avoid flicker from the PWM). For RGB-style colour control, see the NeoPixels lab.
